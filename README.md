
## 🎯 Features

### 🏦 Banking Program
- Simulates basic banking operations
- Deposit and withdrawal functionality
- Account balance management

### 🧮 Calculator Program
- Basic arithmetic operations
- User-friendly interface
- Error handling for invalid inputs

### 🎲 Dice Roller Program
- Random number generation
- Simulates physical dice rolls
- Customizable dice faces

### 🔢 Number Guessing Game
- Interactive game with user input
- Random number generation
- Hint system for better gameplay

### 🌡️ Temperature Converter
- Converts between Celsius and Fahrenheit
- Accurate temperature calculations
- Simple and intuitive interface

### ⚖️ Weight Converter
- Converts between kilograms and pounds
- Precise unit conversion
- Easy-to-use functionality

## 🛠️ Technologies Used

- **Java** - Core programming language
- **Object-Oriented Programming** - Code structure and organization
- **Standard I/O** - User interaction handling
